# Як встановити бота: покроково

Близько 20 хвилин. Безкоштовно. Комп'ютер зручніший, але можна й з телефона в браузері.

**Головне правило:** паролі й токени вписуєте лише в Cloudflare. Нікому їх не надсилайте, у чат теж.

Все інше — об'єкти, інвертори, бойлери, назви, тексти повідомлень, люди — налаштовується в самому боті.

---

## 1. Створити бота в Telegram

1. Відкрийте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте назву, потім адресу, що закінчується на `bot`.
3. BotFather надішле **токен** (довгий рядок з двокрапкою). Збережіть його до кроку 2.

Придумайте також **ключ адміна**: будь-які латинські літери й цифри, 30+ знаків. Запишіть його.

## 2. Розгорнути

1. Натисніть кнопку:

   [![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/vydyshandrey/power-outage-bot)

2. Увійдіть у GitHub і Cloudflare (або зареєструйтесь — це безкоштовно).
3. Cloudflare спитає два секрети:
   - `TG_BOT_TOKEN` — токен з кроку 1;
   - `ACCESS_KEY` — ваш ключ адміна.
4. **Deploy.** Cloudflare сам скопіює проєкт у ваш GitHub, створить базу і запустить бота.
5. Запишіть адресу бота виду `https://home-bot.<ваше-ім'я>.workers.dev` — далі це `<АДРЕСА>`.

> Якщо Cloudflare не спитав секрети: воркер → **Settings** → **Variables and Secrets** → **Add** → тип **Secret**.

## 3. Підключити Telegram

1. Відкрийте в браузері `<АДРЕСА>/setup?key=<ключ адміна>`. У відповіді має бути `"ok":true`.
2. Напишіть своєму боту: `/start <ключ адміна>`.
3. Відповідь «✅ Ти адмін» — бот працює. Внизу з'явиться кнопка **⚙️ Налаштування**.

## 4. Налаштувати в боті

**⚙️ Налаштування → 🏠 Об'єкти → ➕ Додати об'єкт:**

1. Назва: «Дім», «Квартира мами» — як хочете. Об'єкт — це місце; інвертор і бойлер — його пристрої.
2. Бот одразу запропонує додати інвертор. Оберіть застосунок, яким ви його дивитесь: DeyeCloud, SmartESS / WatchPower, SmartClient або SmartValue.
3. Акаунт: «Основний».
4. Бот скаже, які паролі від цієї хмари додати в Cloudflare, з точними назвами. Додайте (як на кроці 2) і натисніть **🔄 Перевірити**.
5. Бот сам зайде в хмару й покаже ваші інвертори — оберіть свій.
   - **SmartValue** списку не дає. Відкрийте в застосунку пристрій → «Деталі пристрою» і надішліть боту по черзі PN, SN, «Протокол зв'язку», «Адреса зв'язку».
   - **Deye**: окрім пароля від DeyeCloud, потрібні `DEYE_APP_ID` і `DEYE_APP_SECRET` — їх видають після реєстрації застосунку на [developer.deyecloud.com](https://developer.deyecloud.com) тим самим email.

Кілька місць (дім, дача, батьки) — додайте кожне як окремий об'єкт. Другий інвертор на тому ж місці: об'єкт → **➕ Інвертор**; з якого брати стан світла — **⚡ Звідки брати світло**. Якщо інвертори в різних акаунтах, оберіть «Акаунт 2» — бот підкаже назви секретів з `_2`.

**⚙️ Налаштування → 🔌 Пристрої → ➕ Додати пристрій** — бойлер Midea:

1. Бойлеру потрібен **окремий** акаунт SmartHome для бота. Створіть його (можна з поштою виду `ім'я+bot@gmail.com`) і з основного акаунта поділіться з ним бойлером. Основний не підходить: застосунок на телефоні почне скаржитися на вхід з іншого пристрою.
2. Бот попросить секрети `MIDEA_EMAIL` і `MIDEA_PASSWORD` — дані цього окремого акаунта.
3. Оберіть бойлер зі списку і об'єкт, до якого він належить.

## 5. Перевірити

- **📊 Статус** показує світло, батарею, бойлер.
- Рядок «Дані …: N хв тому» — не більше ~10 хв.
- Родині дайте посилання на бота й [інструкцію для користувача](user-guide.md). Доступ кожному відкриваєте в **👥 Користувачі → людина → 🔐 Доступ**.

---

## Оновлення

Коли виходить нова версія, бот пише адміну, що змінилось, з кнопкою **⬆️ Оновити**. Налаштування й дані зберігаються.

Щоб кнопка працювала, один раз укажіть свою копію проєкту: **⚙️ Налаштування → 🔗 Репозиторій** → `ваш-логін/назва` (як у адресі на GitHub). Після цього кнопка дає посилання, де натиснути **Run workflow**.

Щоб бот запускав оновлення сам, без переходу на GitHub, додайте секрет `GH_TOKEN`: [github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens) → **Generate new token** → доступ лише до своєї копії → **Actions: Read and write**.

## Якщо щось не так

| Що бачите                         | Що робити                                               |
| --------------------------------- | ------------------------------------------------------- |
| `forbidden` на `/setup`           | Неправильний ключ в адресі                              |
| Бот мовчить на `/start`           | Не відкривали `/setup`, або неправильний `TG_BOT_TOKEN` |
| «Не вдалося увійти в хмару»       | Перевірте логін і пароль у секретах Cloudflare          |
| У статусі «Інвертор ще не обрано» | ⚙️ Налаштування → 🏠 Об'єкти → об'єкт → ➕ Інвертор     |
| Що бачать хмари — для діагностики | `<АДРЕСА>/discover?key=<ключ адміна>`                   |

Не хочете самі — відкрийте ШІ-асистента (Claude, ChatGPT) і вставте текст з розділу «З ШІ-асистентом» у [README](../README.md). Він проведе тими самими кроками.
