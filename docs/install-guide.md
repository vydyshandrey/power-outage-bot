# Як встановити бота: покроково

Близько години, більшість часу йде на реєстрації. Усе безкоштовно. Комп'ютер зручніший, але можна й з телефона в браузері.

Не хочете самі — відкрийте ШІ-асистента (Claude, ChatGPT) і вставте текст з розділу «З ШІ-асистентом» у [README](../README.md). Він проведе тими самими кроками.

**Головне правило:** паролі й токени ви вписуєте лише в Cloudflare (крок 6). Нікому їх не надсилайте, у чат теж.

---

## 0. Що знадобиться

- Telegram.
- Акаунт [GitHub](https://github.com) і акаунт [Cloudflare](https://dash.cloudflare.com/sign-up) — створіть, якщо немає.
- Логін і пароль від застосунку, яким ви дивитесь інвертор.
- Для бойлера Midea — застосунок SmartHome (MSmartHome).

Визначте свій варіант за застосунком інвертора — він знадобиться на кроках 4 і 6:

| Ваш застосунок                    | Варіант       |
| --------------------------------- | ------------- |
| DeyeCloud                         | `deye`        |
| SmartESS, WatchPower, Energy-Mate | `dess`        |
| SmartValue                        | `valueclouds` |

## 1. Створити бота в Telegram

1. Відкрийте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте назву, потім адресу, що закінчується на `bot`.
3. BotFather надішле **токен** (довгий рядок з двокрапкою). Збережіть його, він знадобиться на кроці 6.

## 2. Скопіювати проєкт собі

1. Відкрийте [github.com/vydyshandrey/power-outage-bot](https://github.com/vydyshandrey/power-outage-bot).
2. Зелена кнопка **Use this template** → **Create a new repository**.
3. Назва — будь-яка, можна **Private**. Натисніть **Create repository**.

## 3. Створити базу даних у Cloudflare

1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Storage & databases** → **D1** → **Create**.
2. Назва: `home-bot` → **Create**.
3. Скопіюйте **Database ID**.

## 4. Вписати налаштування

У своїй копії на GitHub відкрийте файл `wrangler.toml` → олівець (**Edit**):

1. Замість `<ID бази D1>` вставте Database ID з кроку 3.
2. У рядку `INVERTER = "deye"` поставте свій варіант з таблиці кроку 0.
3. **Commit changes** (зберегти).

## 5. Розгорнути бота

1. Cloudflare → **Workers & Pages** → **Create** → **Import a repository** (Connect GitHub).
2. GitHub попросить дозвіл — дайте доступ до своєї копії проєкту.
3. Оберіть репозиторій. Назва воркера: `home-bot` (як у `wrangler.toml`). **Deploy**.
4. Дочекайтесь статусу **Ready**. Запишіть адресу бота виду `https://home-bot.<ваше-ім'я>.workers.dev` — далі це `<АДРЕСА>`.

## 6. Додати паролі (секрети)

Воркер `home-bot` → **Settings** → **Variables and Secrets** → **Add**. Тип завжди **Secret**.

**Обов'язково для всіх:**

| Назва          | Що вписати                                                                          |
| -------------- | ----------------------------------------------------------------------------------- |
| `TG_BOT_TOKEN` | токен з кроку 1                                                                     |
| `ACCESS_KEY`   | ваш ключ адміна: будь-який набір латинських літер і цифр, 30+ знаків. Запишіть його |

**Для інвертора — лише свій рядок:**

| Варіант       | Секрети                                                                                                                                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `dess`        | `DESS_USER`, `DESS_PASSWORD` — логін і пароль від SmartESS                                                                                                                                                   |
| `valueclouds` | `VC_USER`, `VC_PASSWORD` — логін і пароль від SmartValue                                                                                                                                                     |
| `deye`        | `DEYE_EMAIL`, `DEYE_PASSWORD` від DeyeCloud, а також `DEYE_APP_ID`, `DEYE_APP_SECRET` — їх видають після реєстрації застосунку на [developer.deyecloud.com](https://developer.deyecloud.com) тим самим email |

**Для бойлера Midea** (якщо є):

1. У SmartHome створіть **другий** акаунт (можна з поштою виду `ім'я+bot@gmail.com`).
2. З основного акаунта поділіться бойлером з другим.
3. Секрети: `MIDEA_EMAIL`, `MIDEA_PASSWORD` — дані **другого** акаунта. Основний не підходить: застосунок на телефоні почне скаржитися на вхід з іншого пристрою.

Після додавання натисніть **Deploy**.

## 7. Знайти свої пристрої

Відкрийте в браузері `<АДРЕСА>/discover?key=<ACCESS_KEY>`. Сторінка покаже номери ваших пристроїв.

Перепишіть їх у `wrangler.toml` на GitHub (розділ `[vars]`) і збережіть — бот розгорнеться сам:

- **Deye:** `DEYE_SN`.
- **SmartESS:** `DESS_PN`, `DESS_SN`, `DESS_DEVCODE`, `DESS_DEVADDR` (рядки там уже є, приберіть `#` на початку).
- **SmartValue:** списку пристроїв ця хмара не дає. Візьміть дані із застосунку: пристрій → **Деталі пристрою**:
  - `VC_PN` — PN;
  - `VC_SN` — SN;
  - `VC_DEVCODE` — «Протокол зв'язку»;
  - `VC_DEVADDR` — «Адреса зв'язку».
- **Бойлер:** `MIDEA_DEVICE_ID`.

Якщо замість номерів бачите `error` — найчастіше це неправильний логін чи пароль на кроці 6.

## 8. Підключити Telegram

1. Відкрийте `<АДРЕСА>/setup?key=<ACCESS_KEY>`. У відповіді має бути `"ok":true`.
2. Напишіть своєму боту: `/start <ACCESS_KEY>`.
3. Відповідь «✅ Ти адмін» — усе працює.

## 9. Перевірити

- **📊 Статус** показує світло, батарею, бойлер.
- Рядок «Дані …: N хв тому» — не більше ~10 хв.
- Родині дайте посилання на бота і [інструкцію для користувача](user-guide.md).

---

## Кілька об'єктів (дім, дача, батьки)

В одному боті може бути кілька місць зі своїми інверторами. Див. розділ «Кілька об'єктів» в [AGENTS.md](../AGENTS.md). Хто який об'єкт бачить, адмін налаштовує в боті: **👥 Користувачі** → **🔐 Доступ**.

## Якщо щось не так

| Що бачите                                      | Що робити                                               |
| ---------------------------------------------- | ------------------------------------------------------- |
| Збірка в Cloudflare падає з помилкою про назву | Назва воркера має бути `home-bot`, як у `wrangler.toml` |
| `forbidden` на `/setup` чи `/discover`         | Неправильний `ACCESS_KEY` в адресі                      |
| Бот мовчить на `/start`                        | Не відкривали `/setup`, або неправильний `TG_BOT_TOKEN` |
| У статусі «Інвертор ще не налаштовано»         | Не вписані номери з кроку 7                             |
