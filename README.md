# home-bot — дім, який сам реагує на відключення світла

[![CI](https://github.com/vydyshandrey/power-outage-bot/actions/workflows/ci.yml/badge.svg)](https://github.com/vydyshandrey/power-outage-bot/actions/workflows/ci.yml)

Коли зникає світло, інвертор переходить на батарею. Електричний бойлер за кілька годин може її розрядити, якщо його вчасно не вимкнути. Стежити за цим вручну незручно: вимкнути, коли світло зникло, не забути увімкнути, коли повернулось, і так кілька разів на день.

**home-bot робить це сам і звітує в Telegram:**

- 🔌 **Світло зникло.** Бот повідомляє, скільки світло було, яке зараз споживання й заряд батареї, і вимикає бойлер.
- 💡 **Світло з'явилось.** Бот повідомляє, скільки світла не було. Коли мережа 5 хвилин стабільна, він вмикає бойлер назад, але лише якщо вимикав його сам.
- 📊 **Статус на кнопці:** напруга, споживання, батарея, стан і температура бойлера.
- 🏠 **Керування пристроями з телефона** та історія: хто, коли й що вмикав.
- 👥 **Сім'я.** Новий користувач надсилає запит, адмін схвалює й обирає права: лише сповіщення, перегляд або керування.
- 🛡 **Спокійно, коли щось ламається.** Якщо хмара виробника на хвилину збоїть, бот мовчки повторює. Якщо за 10 хвилин не вийшло, пише одне зрозуміле повідомлення: «вимкни вручну».

**Працює безкоштовно й без домашнього сервера.** Бот живе в хмарі Cloudflare на безкоштовному тарифі та спілкується з хмарами Deye й Midea так само, як їхні застосунки.

**Що потрібно:** інвертор **Deye** з доступом через DeyeCloud і бойлер **Midea**, яким керують через застосунок SmartHome. Без бойлера бот працюватиме лише як сповіщення про світло.

## Як встановити

### Варіант 1. З ШІ-асистентом (найпростіше)

Відкрий Claude, ChatGPT чи іншого асистента й встав цей текст:

> Допоможи мені розгорнути проєкт https://github.com/vydyshandrey/power-outage-bot для мого дому. Спершу прочитай у ньому файл AGENTS.md і дій строго за ним. Я не програміст: пояснюй простими словами й кажи, що саме мені натиснути. Паролі й токени я вводитиму сам, а не в чат.

Асистент проведе тебе кроками й перевірить результат. Якщо він має доступ до браузера або терміналу (Claude з браузером, Claude Code, ChatGPT у режимі агента), більшість роботи зробить сам. Тобі лишиться зареєструватися в сервісах, ввести паролі й натиснути «дозволити».

### Варіант 2. Самостійно

Покрокова інструкція — у файлі [AGENTS.md](AGENTS.md). Вона однакова для людини й для ШІ. Займає близько години, більша частина якої йде на реєстрації.

## Як влаштовано

```
Інвертор Deye ──► хмара DeyeCloud ──┐
                                     ├──► home-bot (Cloudflare, кожні 2 хв) ──► Telegram
Бойлер Midea ◄── хмара Midea ◄──────┘                │
                                                     └──► база подій і користувачів (D1)
```

### Структура коду

| Файл                          | Відповідає за                                                                |
| ----------------------------- | ---------------------------------------------------------------------------- |
| `src/index.js`                | вхідна точка: маршрути HTTP, вебхук Telegram, розклад                        |
| `src/automation.js`           | перевірка кожні 2 хв: стан мережі, вимкнення й увімкнення бойлера, ескалації |
| `src/bot.js`                  | повідомлення й кнопки в Telegram, ролі та права                              |
| `src/reports.js`              | статус, картка пристрою, історія, звіт про відключення                       |
| `src/deye.js`, `src/midea.js` | клієнти хмар Deye та Midea                                                   |
| `src/db.js`                   | сховище D1: стан, користувачі, права, журнал подій                           |
| `src/config.js`               | пороги й параметри в одному місці                                            |
| `test/`                       | 23 сценарії на імітації хмар і Telegram, без мережі                          |

Налаштування дому зберігаються в `wrangler.toml` (номер інвертора, бойлер, часовий пояс). Паролі й токени — лише в секретах Cloudflare, у коді їх немає.

### Для розробки

```
npm install
npm run check    # ESLint + Prettier + тести
npm run dev      # локальний запуск (wrangler dev)
```

Кожна зміна в `main` проходить ту саму перевірку в GitHub Actions. Історія версій — у [CHANGELOG.md](CHANGELOG.md).

**Чесні обмеження:**

- Дані Deye оновлюються приблизно раз на 5 хвилин, тому реакція на зміну світла — 2–7 хвилин.
- Доступ до Midea неофіційний: так працюють і відкриті бібліотеки для Home Assistant. Хмара Midea інколи збоїть, бот це переживає повторами.

---

**English summary.** A free, serverless Telegram bot (Cloudflare Workers + D1). It watches a Deye inverter and switches a Midea water heater off when the grid goes down and back on after 5 minutes of stable power, but only if it was the one that switched it off. It has roles, per-device permissions, an event history, and silent retries with a single escalation message. Deploy it manually or ask an AI assistant to follow [AGENTS.md](AGENTS.md).
